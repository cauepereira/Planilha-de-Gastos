# MoneyMap 🗺️

Aplicação web de gerenciamento financeiro pessoal. Controle suas receitas, despesas, parcelamentos e categorias com autenticação via Google e dados sincronizados na nuvem.

## Funcionalidades

- Registro de receitas e despesas por mês
- Gestão de compras parceladas
- Categorização de gastos com gráficos
- Histórico mensal com exportação em PDF
- Tema dark/light
- Autenticação via conta Google

## Tecnologias

- HTML5, CSS3, JavaScript (ES Modules)
- Supabase (PostgreSQL + Auth)
- Chart.js, jsPDF
- Vercel (hospedagem)
